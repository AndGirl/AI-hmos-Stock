## 0. 拆分方法（为什么切成这 15 条）

FR-06 在原 PRD 里只有一句「点击进入个股详情」，但设计稿已包含 8 个视觉区块（导航头 / 报价头 / 指标 / 资讯 / 图表 / 盘口 / 内容 / 动作栏）。本次按四条正交线拆分，保证每条**可单独开发、单独验收、单独回滚**：

| 拆分线 | 落点 | 对应条目 |
|---|---|---|
| 用户任务链 | 找到标的 → 看懂行情 → 判断盘口 → 采取行动 | 06.1/06.2 → 06.3~06.8 → 06.9/06.10 |
| 屏幕结构 | 导航头 / 报价头 / 指标 / 资讯 / 图表 / 盘口 / 内容 / 动作栏 | 06.2 ~ 06.10 |
| 跨 FR 依赖 | 凡属别 FR 的能力，只写「消费契约」，不写实现 | 06.1、06.2、06.9、06.10、06.11 |
| 质量属性 | 连接状态、字号、断点、无障碍、性能各自独立成条 | 06.12 ~ 06.15 |

**不拆的方向**（明确排除，避免条目膨胀）：K 线指标算法、资讯/社区内容本身、下单流程、行情推送协议实现——分别归 FR-07、资讯模块、行情中台。

## 2. 关键规则（表内写不下的部分）

### 2.1 承载形态（D20 的落地分析）

D20 原问「独立页还是可嵌入组件」，二者都不是最优解：**只做页**会让 FR-02.10 / FR-05.10 的右栏各自实现一套；**只做组件**会让深链、返回、沉浸式、动作栏无处安放。建议采用 **壳 / 内容分离**：

```
DetailPage（壳）     路由、返回栈、沉浸式、窗口尺寸、动作栏
   └─ DetailContent（内容）  头部 / 指标 / 资讯 / 图表 / 盘口 / 内容Tab
        props: { code, mode: 'page' | 'pane' | 'window', compact: boolean }
        events: onAction(etype), onLoaded(code)
```

约束（任一条不满足即视为实现偏离）：

| 编号 | 约束 |
|---|---|
| INV-D1 | `DetailContent` 内禁止 `router.push/pop`、禁止创建全局 banner、禁止启动重连定时器 |
| INV-D2 | 同一 `code` 的周期选择、指标展开态在 `page`↔`pane` 切换时保持 |
| INV-D3 | 每个 `window` 实例独立持有 `code` 与订阅，互不影响（FR-08 双股/三股比价） |
| INV-D4 | 任一时刻「去交易」在全页只能有一个入口 |

### 2.2 指标面板的断点映射

| 断点 | 设计稿 | 展示项数 | 列数 | 展开后 |
|---|---|---|---|---|
| sm（375） | 直板机 | 6（今开/昨收/换手率 · 最高/最低/市盈率） | 2 列 × 3 行 | 12 项，2 列 × 6 行 |
| md（700） | — | 9 | 3 列 × 3 行 | 12 项，3 列 × 4 行 |
| lg（1000） | 折叠展开 | 9 | 3 列 × 3 行 | 12 项，3 列 × 4 行 |
| xl（1180+） | 平板 | 12 | 4 列 × 3 行 | 12 项，4 列 × 3 行 |

指标优先级序（决定 sm 取前 6、md/lg 取前 9）：**今开 → 昨收 → 换手率 → 最高 → 最低 → 市盈率 → 成交量 → 成交额 → 总市值 → 振幅 → 量比 → 流通市值**。
`fontScale` 每升一档列数减 1：xl 4→3→2、lg/md 3→2→1、sm 2→1→1（**下限 1 列**）。**只降列，不缩字号、不截断、不省略号**（CC-6.5）。

### 2.3 图表周期与坐标

| 周期 | 数据粒度 | X 轴 | 说明 |
|---|---|---|---|
| 分时 | 1min × 241 点 | 09:30 / 11:30-13:00 / 15:00（午休不占宽） | 昨收虚线基准 + 均价线 + 量柱；Y 轴对称于涨跌停 |
| 五日 | 5 × 241 点 | 按日等分 | 跨日分隔线，昨收基准取第 1 日 |
| 日/周/月/季/半年/年 K | 前复权，默认 120 根 | 日期 | 蜡烛 + 量柱；上滑加载更早，最多 500 根 |

周期 Tab 固定 **8 个**（含年K），用 **List + ForEach** 横向滑动展示，不按断点裁剪条目；间距按断点 12 / 14 / 16 / 20vp，首尾保留 16vp 内边距，滑动时首尾不被裁切。
图表统一由**三方库**绘制：切换 Tab 即按新周期重新绘制（同一容器、仅换 series），不得复用上一周期画面；K 线缩放比例按周期各自记忆，切回不重置。

### 2.4 盘口与成交明细

- **位置**：盘口与成交明细固定挂在图表右侧、同顶对齐，宽约 30%（sm 约 102vp，上限 170vp）；图与盘口同处一行，不上下堆叠。周期切换、指标展开、字号变化都不得改变该相对位置。
- **内部顺序**（自上而下）：`五档行情` 标题（粉底）→ 卖1~卖5 → 红绿比例条 → 买1~买5 → `成交明细` 标题（灰底）→ 逐笔列表（默认 20 条，可视约 4 条，区内滚动）。
- **红绿比例条**：红段=委买总量占比、绿段=委卖总量占比，两段按比例铺满整宽；占比低于 5% 或高于 95% 时按 5% 钳制，避免细到看不见；停牌时整条隐藏。
- **成交明细**：时间/价格/量三列，按时间倒序；20 条超出可视高度时区内滚动，不撑高盘口；方向按主动买卖着色。
- 五档价格着色按**相对昨收**，不按相邻档；量单位「手」，右对齐等宽。
- 中间红绿比例条 = 委买总量 / 委卖总量，比例 <5% 或 >95% 时按最小 5% 绘制，避免视觉失真。
- 成交明细默认 20 条；同一秒多笔不合并；方向按主动买卖着色。
- 推送合并窗口 **1s**，与 FR-02.7 列表保持一致；连续变动只闪一次（300–500ms）。
- 停牌、未开盘、收盘后（15:00 之后）：五档保留最后快照并整体置灰，明细保留最后 20 条不再追加。

### 2.5 详情页状态矩阵

| 状态 | 头部 | 图表 | 盘口 | 动作栏 |
|---|---|---|---|---|
| 首次加载 | 骨架 | 骨架 | 骨架 | 置灰 |
| 正常 | 实时 | 实时 | 实时 | 可点 |
| 首屏失败 | 错误态 + 重试 | — | — | 仅「返回」 |
| 图表局部失败 | 保留 | 局部错误 + 重试 | 保留 | 可点 |
| 离线（有缓存） | 冻结 + 置灰 | 冻结 + 置灰 | 冻结 | 去交易禁用 |
| 离线（无缓存） | 错误态「网络异常」 | — | — | 仅「返回」 |
| 停牌 | 价格类 `--` + 「停牌」 | 历史可看 | `--` 置灰 | 去交易禁用 |
| 新股 | 昨收/涨跌 `--` + 「新」 | 无历史→空态 | 正常 | 可点 |
| 退市 / 不存在 | 404 态 | — | — | 隐藏 |

### 2.6 紧凑版（pane / window）组成（v1.1）

> 依据 06.3–06.10 的最新调整重生成。紧凑版不是「缩小版整页」，而是**只保留预览必需的区块**。

| 区块 | 规则 |
|---|---|
| 头部 | 名称 / 代码 / 市场 / 状态 + 行情时间；右上「⋯」；**无返回** |
| 报价 | 价格 + 涨跌 + 涨跌幅，与 page 同一套着色与空值规则 |
| 指标 | 6 项 / 2 列；保留展开 chevron，展开为 12 项（2 列 × 6 行，pane 内滚动） |
| 周期 Tab | 8 个（含年K），List + ForEach 横滑；pane 间距 14vp |
| 图表 + 五档/成交明细 | **pane ≥360vp**：图表与右列并排（右列 = 五档 + 比例条 + 成交明细，约 32%、上限 132vp，同顶）；**pane <360vp**：图表在上，五档左右两列 + 比例条 + 成交明细在下（明细区内滚动） |
| 资讯条 | 不显示 |
| 内容 Tab | 不显示 |
| 动作栏 | 不显示；四项动作收进「⋯」菜单（自选设置 / 股票PK / 更多 / 去交易；停牌时去交易置灰） |

补充约束：
- pane 内点击不产生路由，只替换 `code` 并按 06.7 刷新图表；
- window 每个实例独立持有 `code`、周期与图表实例，关闭只销毁该实例；
- 嵌入实例不得渲染全局 banner，不得启动重连定时器（CC-7.3）；
- 紧凑版与 page 共用同一内容组件，仅由 `compact` 参数切换上述区块的显隐。

## 3. 数据契约（建议）

```ts
StockDetail = {
  code, name, market: 'SH' | 'SZ' | 'BJ',
  tags: string[],                       // 只含板块/状态，不含分组（CC-2.9）
  status: 'pre' | 'auction' | 'open' | 'lunch' | 'closed' | 'suspended' | 'delisted',
  serverTime: number,                   // 行情快照时间，非设备时间
  quote: { last, prevClose, open, high, low, chg, pct,
           volume, amount, turnover, pe, pb, amplitude, volumeRatio,
           marketCap, floatCap, limitUp, limitDown },
  orderBook: { asks: Order[5], bids: Order[5], bidVol, askVol },
  ticks: Tick[20],                      // { time, price, vol, dir }
  chart: { period: 'timeline'|'five'|'d'|'w'|'m'|'q'|'hy', adjust: 'qfq', points: Point[] },
  news: { id, title, ts } | null,
  added: boolean                        // 读自选仓储，不缓存（CC-3.7）
}
```

订阅：`subscribe(code) → { seq, patch }`，页面退出/切 code 必须 `unsubscribe`；`patch` 走增量，禁止整对象替换触发全量重绘。

## 4. 与相邻 FR 的边界

| 相邻 FR | 谁负责 | 本 FR 的义务 |
|---|---|---|
| FR-02 列表 | 进入动线与右栏选中联动 | 提供 `DetailContent`，返回时恢复列表滚动与选中 |
| FR-03 卡片视图 | 视图与排序 | 卡片点击进详情，不在详情内改视图 |
| FR-04 自选管理 | 加/移/改分组的全部规则 | 「自选设置」只调用其弹层与提交逻辑（E4 入口） |
| FR-05 搜索 | 匹配、防抖、离线查询 | 详情页内**不得**再写搜索/匹配 |
| FR-07 交易 | 买入弹窗与委托 | 「去交易」只做跳转与参数透传，不校验交易规则 |
| FR-08 多窗/比价 | 窗口创建、布局、同步、PK 组（见 `fr08-subreq.md`） | 每窗一个实例；详情自身不感知窗口数量；右上「⧉」入口与窗序归 FR-08，详情只提供内容组件 |
| 资讯 / 社区 / 研报 | 内容与列表 | 只提供 Tab 容器、默认 Tab 与占位态 |
