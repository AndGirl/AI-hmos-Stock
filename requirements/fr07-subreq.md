# FR-07 交易（买入委托）· 子需求条目表

> 版本：v1.0 · 编制：2026-11-11 · 状态：**待评审**
> 效力：受 `fr-common-spec.md`（CC-6 / CC-7）约束；行情快照、账户与可买额度、撮合受理分别由行情中台 / 账户中心 / 交易网关提供，本 FR **只消费**。
> 范围：从详情页「去交易」到买入委托回执的**全部前端交互**——入口前置、弹窗承载、价格与数量、校验、二次确认、提交结果、关闭与中断、多端与无障碍、埋点与性能。
> 验收：本 FR 原无 AC，**建议新增 AC-66 ~ AC-76**（编号待与 PRD 主文档对账，见 §7）。
> 设计依据：`design/*-买入股票弹窗.png`、`design/*-确认买入股票弹窗.png`（直板机 / 折叠展开 / 平板，各 2 层）。
> 验证件：`validation/fr07-trade-validation.html`（20 条自动用例，**不计入需求文档**）。
>
> **本版要点**
> - 入口禁用只覆盖 **未开户 / 无权限 / 停牌 / 退市**；未登录走「登录回流」，非交易时段**允许开单不可提交**。
> - 本期仅**普通交易（限价委托）**；价格与数量**步进 + 手输**双向同步，只按 100 股整手校验。
> - 提交按**真实委托**口径定义：幂等键、三态结果、超时进入「结果未知」且禁止自动重发。

## 0. 拆分方法（为什么切成这 14 条）

FR-07 在既有文档里只有一句「买入弹窗与委托」（`fr06-subreq.md:179`），而设计稿已包含 2 层弹窗 × 3 种形态、6 类输入状态、3 种提交结果。本次沿四条正交线拆分，保证每条**可单独开发、单独验收、单独回滚**：

| 拆分线 | 落点 | 对应条目 |
|---|---|---|
| 用户任务链 | 触发入口 → 填单 → 校验 → 二次确认 → 提交 → 结果 | 07.1 → 07.4/07.5 → 07.6 → 07.7 → 07.8 |
| 屏幕结构 | 入口位、弹窗壳、上下文区、价格行、数量行、主按钮、确认层 | 07.1 ~ 07.7 |
| 跨 FR / 外部依赖 | 账户、网关、行情快照只写「消费契约」，不写实现 | 07.3、07.8、07.11 |
| 质量属性 | 状态矩阵、多端、字号无障碍、埋点、性能各自独立成条 | 07.9 ~ 07.14 |

**不拆的方向**（明确排除，避免条目膨胀）：撮合与成交回报、开户 / KYC、资金划转、风控规则引擎本体、行情推送协议、委托列表与撤单——分别归交易中台、账户中心、风控、行情中台与后续 FR。

## 2. 关键规则（表内写不下的部分）

### 2.1 三形态的弹窗壳

| 形态 | 设计稿 | 壳形态 | 宽度 | 高度 | 说明 |
|---|---|---|---|---|---|
| sm 直板机（375） | 496×1026 | 底部 sheet | 近满宽（左右 8vp 内边距） | 随内容，≤90% 屏高 | 贴底、上圆角、预留 home indicator 安全区 |
| md 折叠展开（700） | 988×1102 | 底部 sheet | 近满宽 | 随内容，≤88% | 同上，按钮区留 16vp 底距 |
| lg 阔折叠（1000） | — | 居中模态 | 640vp | 随内容，≤82% | 圆角 22vp，四周留白 |
| xl 平板（1180+） | 1602×1035 | 居中模态 | 640vp | 随内容，≤82% | **宽度不随屏宽放大** |

约束：

| 编号 | 约束 |
|---|---|
| INV-T1 | 同一 `clientOrderId` 只允许成功受理一次 |
| INV-T2 | 弹窗任一时刻只渲染一个层（编辑 或 确认），不得并存 |
| INV-T3 | 提交中所有关闭入口失效，且只有一条提示 |
| INV-T4 | 弹窗归属创建它的窗口，不得跨窗模态 |
| INV-T5 | 无可用账户或未开户时，任何路径都不得进入确认层 |

### 2.2 状态矩阵（8 业务态 + 2 过程态）

| 状态 | 入口「去交易」 | 弹窗 | 主按钮 | 文案 | 依据 |
|---|---|---|---|---|---|
| 未登录 | **可用** | 先弹登录层，登录成功**回到原标的并自动续开** | 登录后可点 | — | DEC-07-07 |
| 正常 | 可用 | 直接打开编辑层 | 可用 | — | — |
| 未开户 / 无权限 | **禁用** | 不打开 | — | 「请先开通交易账户」 | FR-07.1 |
| 停牌 | **禁用** | 不打开 | — | 「停牌期间不可交易」 | FR-06.10 |
| 退市 / 不存在 | **禁用** | 不打开 | — | 「已退市，不可交易」 | FR-06.10 |
| 非交易时段 | **可用**（可查看可买） | 打开，字段可编辑 | **禁用** | 「非交易时段，暂不可委托」 | DEC-07-04 |
| 资金不足 / 可买 &lt; 100 | 可用 | 打开 | **禁用** | 「可买 `{n}` 股，资金不足」 | — |
| 断线 `offline` | 可用 | 打开，内置单条提示 | **禁用** | 「行情连接中断，暂不可委托」 | CC-7.6（待增补） |
| 提交中（过程态） | 不适用 | 锁定，所有关闭入口失效 | loading「提交中…」 | 「委托提交中，暂不可关闭」 | FR-07.9 |
| 结果未知（过程态） | 不适用 | 锁定，仅「查询委托」与关闭 | 禁用 | 「结果未知，请先查询委托」 | FR-07.8 |

> **判定优先级**：登录 → 开户/权限 → 停牌/退市 → 断线 → 交易时段 → 资金。前两栏在**入口**判定，其余在**弹窗内**判定；这条边界必须写进实现，否则会把交易时段错误地拦在入口。

### 2.3 价格规则

| 项 | 规则 |
|---|---|
| 默认值 | 进入弹窗时取当前价，`round(,2)` |
| 步进 | `±0.01`，每次点击后 `round(,2)` |
| 区间 | `[跌停, 涨停]`，越界 `clamp` 到边界并提示「已按涨停价 X 修正」 |
| 涨跌停来源 | **昨收 × 板块幅度**（主板 ±10%），由行情推导；设计稿数值视为占位 |
| 手输 | 点击数值变为输入框，`Enter` 或失焦提交；非数字/空值拒绝并保留原值 |
| 精度 | 恒两位小数，`tabular-nums`；不显示货币符号 |

### 2.4 数量规则

| 项 | 规则 |
|---|---|
| 默认值 | 100 股（可买不足 100 时置 0 并禁用主按钮） |
| 步进 | `±100`，下限 100，上限 = 可买 |
| 整手 | 仅按 **100 股整数倍**校验；本期不做科创板 200 股分支 |
| 超可买 | 手输超限 → 回填为可买（向下取整到手）并提示 |
| 联动 | 改价格或数量后重算可用上限；不触发任何下单请求 |

### 2.5 校验与错误文案

> 表中 `{}` 为占位符，渲染时替换为实时值（价格两位小数、数量为整数）。

| 场景 | 位置 | 文案 |
|---|---|---|
| 价格为空 / 非数字 | 价格行下方 | 请输入数字 |
| 价格高于涨停 | 价格行下方 | 不得高于涨停价 `{limitUp}` |
| 价格低于跌停 | 价格行下方 | 不得低于跌停价 `{limitDown}` |
| 数量为空 / 为 0 | 数量行下方 | 请输入委托数量 |
| 非整手 | 数量行下方 | 委托数量须为 100 股整数倍 |
| 超可买 | 数量行下方 | 超过可买 `{canBuy}` 股 |
| 未开户 | 入口 toast | 请先开通交易账户 |
| 停牌 / 退市 | 入口 toast | 停牌期间不可交易 / 已退市，不可交易 |
| 非交易时段 | 弹窗内提示条 | 非交易时段，暂不可委托 |
| 断线 | 弹窗内提示条 | 行情连接中断，暂不可委托 |
| 资金不足 | 弹窗内提示条 | 可买 `{n}` 股，资金不足 |
| 提交中 | toast | 委托提交中，暂不可关闭 |
| 结果未知 | 确认层卡片 | 结果未知，请先查询委托 |

### 2.6 提交、幂等与结果

| 项 | 规则 |
|---|---|
| 幂等键 | 进入弹窗生成 `clientOrderId`，本次流程内**所有重试复用**；成功后作废 |
| 提交前 | 按钮进入 loading，禁用关闭入口；重复点击直接丢弃 |
| 成功 | 记录委托号与状态（已报 / 已成交 / 部分成交）→ toast → 700ms 后关闭弹窗回详情 |
| 失败 | 弹窗内展示原因（资金不足 / 超出涨跌停 / 非交易时段 / 风控拦截），保留输入可改可重试 |
| 超时 | 2s 无响应进入「结果未知」：**不自动重发**，只提供「查询委托」；主按钮禁用，关闭不受限 |
| 计时 | 提交计时由弹窗自身管理，关闭即释放，不得残留定时器 |

### 2.7 关闭与中断矩阵

| 路径 | 编辑层 | 确认层 | 提交中 |
|---|---|---|---|
| 右上「X」 | 关闭并丢弃输入 | 关闭整个流程 | **禁止** + 提示 |
| 点遮罩 | 关闭并丢弃输入 | **不关闭**（防误触） | **禁止** |
| 系统返回 / 侧滑 | 关闭 | 回编辑层（保留输入） | **禁止** |
| 切后台 | 保留 | 保留 | 保留并继续等待结果 |
| 成功后自动关闭 | — | 关闭回详情（不可拦截） | — |

### 2.8 埋点与合规

| 事件 | 触发 | 字段 |
|---|---|---|
| `entry_click` | 点「去交易」 | `code`、`source`、是否被前置拦截 |
| `modal_open` | 弹窗打开 | `code`、账户、可买 |
| `value_change` | 价格 / 数量变更 | 字段、旧值、新值、来源（步进 / 手输） |
| `confirm_view` | 进入确认层 | 价格、数量 |
| `submit` | 提交 | `clientOrderId` |
| `result_success` / `result_fail` / `result_unknown` | 回执 | 委托号或错误码（**金额脱敏**） |

合规：真实委托下，账号、持仓、金额、委托明细**不得上报三方**；日志不落盘明文；截图/分享不含账户信息；埋点失败不阻塞下单。

## 3. 数据契约（建议）

```ts
TradeContext = {
  code, name, market,                 // 标的；展示用脱敏 code
  account: { id, maskNo, available, holdQty, maxBuyQty },
  quote:   { last, prevClose, limitUp, limitDown, tradeStatus, snapshotTime },
  source:  'detail' | 'pane' | 'deepLink',
  permission: { loggedIn, opened, canTrade }
}

OrderDraft = { code, accountId, side: 'buy', price, qty, clientOrderId }

OrderResult = {
  clientOrderId,
  orderId?: string,
  status: 'accepted' | 'rejected' | 'unknown',
  code?: string,        // 错误码，映射到 §2.5 文案
  message: string,
  ts: number
}
```

- 价格与数量在前端只做**格式与区间**校验，业务规则（额度、涨跌停、T+1）以网关返回为准。
- `clientOrderId` 由前端生成、流程内复用；网关需按它做去重。
- 弹窗关闭即释放上下文，不缓存草稿（除切后台保活）。

## 4. 与相邻 FR 的边界

| 相邻方 | 谁负责 | 本 FR 的义务 |
|---|---|---|
| FR-06 详情 | 「去交易」按钮位置、停牌/退市置灰、参数透传 | 只接收 `code` + 参考价 + 来源位，不自带入入口与状态判断以外的职责 |
| FR-08 多窗 | 窗口创建、布局、同步（见 `fr08-subreq.md`） | 弹窗跟随所在窗口，不做跨窗模态；全局同一时刻仅允许一个弹窗实例 |
| 行情（快照/盘口） | 最新价、昨收、涨跌停 | 只读取；涨跌停由昨收推导，不缓存二次推导结果 |
