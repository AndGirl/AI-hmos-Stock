- 调试：长按「普通交易」标题（debug）打开两级菜单——未登录 / 未开户 / 断线 / 非交易时段 / 更多故障（资金不足、拒单、提交超时）/ 恢复正常；对应 `MockFaults.trade*` 与 `TradeAuth`，release 由 `BuildProfile.DEBUG` 关闭。

## E. 常见坑全集

1. **HAR 入口位置**：`oh-package.json5` 的 `main` 指向**模块根** `Index.ets`，不是 `src/main/ets/Index.ets`；否则报 `00304003 Invalid main file`。
2. **移动模块路径后增量缓存脏**：出现 `symbolMap.map` 路径错误或旧 `entry/build` 引用，执行 `devecocli build clean` 后重建。
3. **沙箱**：workspace-write 下用 PowerShell `New-Item` 建多级目录会被拒；优先用写入工具创建文件（自动建目录），删除/移动集中走一条提权命令。
4. **`BuildProfile.ets`** 是 hvigor 生成物，已在 `.gitignore`；不要手改或提交。
5. **TabContent** 不能脱离 `Tabs`；默认 TabBar 用 `barHeight(0)` 隐藏，自绘底栏叠加在 `Stack` 上。
6. **`.navDestination` 只能调一次**，多次链式会后者覆盖前者；在单一 builder 内 `if/else` 分派。
7. **`@Builder` 多参数不刷新**；需要刷新时用单对象参数或拆组件。
8. **toast 截图**：1.8s 很短，用 §7 的 hdc 连拍命令，不要用两次 CLI 往返。
9. **`$r` 可用于类静态常量**（`ComingSoonText`/`TokenRegistry` 已验证），但仅限 `.ets` 且资源存在。
10. **`AppStorageV2.connect` 在 EntryAbility 中可用**（已实测），组件侧用 `@Local` 持同一实例即可获得 `@Trace` 刷新。
11. **NavDestination 取参**：API 20 的 `pathInfo.param` 是 `unknown`，不能直接赋给 `Object`；先判 `!== undefined` 再 `as DetailParam`。
12. **多设备**：`devecocli run` 必须带 `--device`（当前有模拟器 Pura X Max + 实体 Mate 60 Pro），否则报 `Multiple devices found`。
13. **深链联调**：`aa start -U` 不带 `-a/-b` 也能验证 skills；冷启动前先 `aa force-stop`，热启动直接再发一次 URI。
14. **onNewWant**：只处理 `onCreate` 会导致应用已运行时收到深链无反应；冷/热两个入口都要接。
15. **全屏 + Navigation**：全屏后 Navigation 不会自动避让状态栏，NavDestination 标题栏会顶到状态栏；在 Navigation 上加 `.padding({ top: topInset })` 可同时避让 navBar 与所有目标页。
16. **全屏底部**：Tabs 与 NavDestination 内容都要手动避让；本项目 Tabs 吃 `bottomInset`，详情/比价内容 `bottomInset + 16`，底栏 `bottomInset + 8`。
17. **门禁扩展**：新增 feature 横向依赖必须同步设计 §3.1.2/§3.1.10 与 `check-architecture.mjs` 的 `ALLOWED_FEATURE_EDGES`，否则 R-04 直接拦下。
18. **ArkTS 对象字面量**：`private listener = { onPatch: ... }` 这类**未声明类型**的字面量会编译失败（arkts-no-untyped-obj-literals）；给变量/返回标注接口类型仍可能被拒，稳妥做法是写 `class X implements 接口`。
19. **名称列 translate 会盖住表头**：`Column.translate({y:-vOffset})` 只改视觉位置、不参与布局，内容会画到表头区域上；外面必须套 `Stack(...).clip(true)` 做裁剪，且 Stack 本身不 translate。
20. **横向 Scroll 的横滑条遮挡末行**：内容 `Column` 加 `padding({ bottom: 8 })` 给滚动条留位，否则最后一行被 4vp 横滑条压住。
21. **List 在横向 Scroll 内**用 `List({ scroller })`，`List(scroller)` 旧签名在 API 20 编译失败；`onScroll` 已废弃，改用 `onDidScroll`。
22. **@Monitor 嵌套路径**：`@Monitor('row.quote.flashSeq')` 可监听 `@Param` 持有的 `@ObservedV2` 对象字段（用于逐行高亮），前提是中间对象都是 `@ObservedV2` + `@Trace`。
23. **ForEach 刷新陷阱**：`ForEach(rows, ..., key=code)` 在数组里换成**新实例**时，同 key 的旧节点可能继续读旧对象（表现为空态后分组只数仍是旧值、重载后价格不刷新）。VM 侧必须按业务 key **复用实例**再改 `@Trace` 字段。
24. **xl 只改 metrics 不够**：只把 `computeTableMetrics` 的 viewport 设成 523、但容器仍 `width('100%')`，会得到「全宽表格 + 假分栏」；必须把列表内容列宽约束到 523，右栏单独占位。
25. **ActionSheet 限制**：`promptAction.Button` 的 `color` 必填，`buttons` 是 0~6 元组（超过 6 个编译失败）；调试菜单最多 6 项。
26. **字号默认不跟随系统**：HarmonyOS 应用默认 `nonFollowSystem`，`Configuration.fontSizeScale` 恒为 1（fp 也不放大）；需 `AppScope/app.json5` → `"configuration": "$profile:configuration"`，profile 里配 `fontSizeScale: followSystem` 与 `fontSizeMaxScale`，改完必须**重装**应用才生效。改系统字号会触发 `onConfigurationUpdate` 并可能把应用切到前台（调试时注意）。
27. **横向 List 跨窗口尺寸会保留像素偏移**：指数条折叠↔展开后可能从中间某只开始（表现像数据错位，实为 scroll offset 未复位）。数据/布局版本变化时用 `Scroller.scrollToIndex(0)`（放在 `@Monitor('version')` 里）复位；不要试图靠数据源 `onDataReloaded()` 重置。
28. **横向 `Scroll` 内容不足时居中**：分组 Tab 用 `Scroll` 时 5 个 Tab 在 940vp 下会整体居中，无法满足「始终居左」。改用 `listDirection(Axis.Horizontal)` 的 `List`（内容不足同样左对齐、超出可滑），或给内容加 `width('100%')` 的占位撑满（后者会阻断横滑）。
18. **页面状态计时器**：占位加载/重试用 `setTimeout`，必须在 `aboutToDisappear` 清理，否则返回后仍会改已销毁页面的状态。
29. **mpchart 组件与 model 成对**：`LineChart({ model })` / `CandleStickChart({ model })` / `BarChart({ model })`；model 只在 `commons/data/chart` 创建，view 只透传。切周期换组件但**不换 model**，数据更新靠 `setSeries` + `notifyDataSetChanged()` + `invalidate()`。
30. **`UIContext` 没有 `resourceManager`**：要 `getUIContext().getHostContext()` 拿 `common.Context` 再取 `resourceManager.getColorSync($r(...))`；颜色值注入给图表，data 层保持零颜色字面量。
31. **`Stack` 内的 `height('100%')` 会撑满父级**：无固定尺寸的 Stack 里放 `Row().width('100%').height('100%')` 会让 Stack 取父容器可用高度，整个报价头被顶到屏幕中部（本轮踩过）。闪底用「同尺寸文字 + 背景色」叠层，不要百分比尺寸。
32. **`dayStart` 不能用 `ts - ts % DAY_MS`**：那是 UTC 零点，UTC+8 下分时 X 轴会显示 17:30/19:10；要用 `new Date(ts).setHours(0,0,0,0)`。
33. **`List` 没有 `.barState()`**：只有 `.scrollBar(BarState.Off)`；写了 `.barState()` 直接编译失败。
34. **`@Local` 持有 VM 不要在 `aboutToAppear` 重新 `new` 再赋值**：视图可能仍观察旧实例（表现为详情永远停在骨架）。改用 `vm.attach(code)` 复用同一实例。
35. **R-05 是正则 `new (Mock|Real)\\w*`**：`new MockDetailSubscription` 这类实现类也会被拦；订阅/实现类不要以 `Mock`/`Real` 开头（改名 `DetailSubscriptionImpl`）。
36. **R-07 要求 view 只 import viewmodel**：`commons_data` 的类型与 mpchart 适配原语要经 `viewmodel/DetailExports.ets` 再导出，view 不得直接 import `commons_data` 或 `repository/`。
37. **mpchart Dataset 没有 `setColor`**：用 `setColorsByArr([color])`；`BarData` 只接受 `JArrayList<IBarDataSet>`（`BarDataSet[]` 会编译失败）。
38. **mpchart Y 轴/图例为空**：`getLegend()`、`getDescription()`、`getAxisLeft/Right()` 都可能返回 `null`；X 轴 formatter 按 index 反查 `ts` 数组，切周期必须重设 formatter 数据。
39. **嵌套 ForEach 的行 key 不能只用行号**：指标面板展开时外层 `ForEach` 若用 `'row-' + index`，行数变化后旧行节点被复用、内层不重建，出现「最高/最低/市盈率」重复。行 key 必须由该行单元格 key 拼接（内容变化即换 key），本次用 `rowKey(row)`。
40. **设计稿的指标列是「组」不是「行」**：按行优先填充会把 sm 的 2 列排成「今开·昨收 / 换手率·最高…」；必须列优先（每列一组、列内按优先级自上而下），才能与直板机/折叠/平板三张稿一致。

**M4 新增（多窗）**

41. **`DataServices` 静态字段与方法同名**：`private static detailSubs` 与 `static detailSubs()` 同名时，方法调不动（报 `Cannot invoke an object which is possibly 'undefined'`）；字段改名 `detailSubsRegistry`。
42. **`onFocus` 是组件内建属性**：`@Event onFocus` 会与 `CustomComponent.onFocus` 冲突编译失败；事件名改用 `onSelect/onActivate` 一类自定义名。
43. **`AppDim.*` 是 Resource 不是 number**：`AppDim.gap8 * 2` 这类算术会编译失败；尺寸计算用本地 number 常量（如 `FRAME_PADDING = 8`）。
44. **view 不能 import `repository/`**（R-07）：`PkLayout` 的类型/常量要在 `viewmodel/PkVM.ets` 末尾**再导出**，视图从 viewmodel 取。
45. **`Text()` 不接受 Resource 与 string 的三元**：`Text(cond ? $r(...) : '')` 报「No overload matches」；改用 `if/else` 两个 `Text`，或两个 Resource 的三元（`accessibilityText` 同）。
46. **mpchart 视口变化后必须重设数据**：窗数变化（2↔3 窗、折叠/展开）后仅 `resetZoomFor` 不够，K 线会挤在一侧；要在下一帧后 `setSeries(series)` 再 `resetZoomFor`（`ChartArea.reflow`，80ms 防抖 + token 防串号）。
47. **PersistenceV2 单窗不落盘**：进入 PK 时只带 1 只，若此时也 persist 会把上一组真组合覆盖成单窗，恢复永远失败；`PkVM.persist()` 在 `windows.length < 2` 直接返回。
48. **多选态要四处一起改**：`WatchlistVM.selectMode/selectedCodes` + `NameCell`（勾选圈）+ `QuoteRow`（整行浅底）+ `FrozenTable`（透传选中集）+ 页面底部选择栏；只改一处会出现「名称列有圈、数字列不高亮」。
49. **窗卡里再套 `PanGesture` 会吞点击**：点窗体内图表/滚动区不一定触发窗卡 `onClick`（聚焦）；实测点窗头或指示器稳定，验收时按此路径操作。
50. **计数类日志要按「当前窗数」断言**：布局自检在 `windows.length === 0` 时会误报 `slot_count 1 != 0`；`checkLayout` 先判空，`computeLayout(0)` 返回空数组。
**M5 新增（断线/埋点/性能）**

51. **调试注入断线必须同时改 `MockFaults.netFault`**：只调 `hub.force('offline')` 会在 1s 退避后探活成功自动回 online（表现为「刚断就恢复」）；`probe` 读的是 `MockFaults.netFault`，两者必须一致。
52. **PowerShell 的 `$pid` 是只读自动变量**：取应用进程用 `$appPid = (hdc shell "pidof <bundle>").Trim()`，`/proc/<pid>/status` 里读 `VmRSS/VmHWM`；`/proc/<pid>/fd` 在非 root 下不可读。
53. **ActionMenu 最多 6 个按钮**：加网络/字号档位时不要硬塞，改成「字号…」「网络…」二级菜单（本项目调试面板已这样分层）。
54. **banner 会改变页面高度**：`GlobalBanner` 占 28vp，挂在 Tabs/详情/PK 顶部会让内容整体下移；断线/弱网来回切时属预期跳动，不要用 `Stack` 叠层规避（会挡内容）。
55. **`lastPatch` 不要在冻结时更新**：否则恢复焦点时 flush 出去的是断线前的旧帧，表现为「断线期间价格偷偷变了」；冻结期直接 return。
56. **组件事件名避开内建属性**：`onFocus`（焦点事件）已被 ArkUI 占用，自定义事件用 `onSelect/onActivate` 一类名字，否则报「not assignable to CustomComponent」。
57. **`Text()` 不接受 `Resource | string` 的三元**：`Text(cond ? $r(...) : '')` 直接编译失败；改 `if/else` 两个 `Text`，或两个 Resource 的三元（`accessibilityText` 同）。
58. **`uitest` 的 `doubleclick` 不等于读屏的「双击激活」**：开启屏幕朗读后，`devecocli ui click` 只移动焦点，`doubleclick` 也常常只聚焦不激活；想自动化验证切窗/播报，要么先关读屏，要么改用「点窗标题/指示器」这类明确的按钮节点。
59. **内容宽不要用「合理值兜底」**：`Math.max(200, slot.width - padding)` 会让 133vp 的窗卡内容按 200vp 排，右侧直接裁掉；兜底值只能防负数，不能防「比容器还宽」。
60. **窄屏文字要成组降级**：388vp 三窗时价格 22fp + 涨跌 11fp 横排必裁；`maxLines(1)` 只把「裁切」变成「省略」，真正解法是按宽度换字号或换行（本次 mini 头部：价格 18fp、涨跌另起一行）。
61. **成交明细的固定列宽要跟盘口列宽联动**：时间 48vp + 量 34vp 在 116vp 的盘口列里只剩 26vp 给价格，`1668.89` 必换行；按 `panelWidth` 比例分列（34%/20%）并保底 34/22vp 才稳。
62. **调试面板改字号只改几何**：`ConfigService.fontScale` 影响列宽/列数/经营几何，文字是 `fp` 跟**系统字号**；字号端到端必须去系统设置改「字体大小」再冷启动，否则只会看到列变少、字没变。
63. **固定宽数值列在 1.45× 必换行**：交易价格/数量原为 `width(96)`，7 位数字放大后换行并把「+」挤出字段；数值列用 `layoutWeight(1) + constraintSize(maxWidth) + maxLines(1)`，把步进按钮放在固定宽的外层。
64. **窄窗头部要分优先级**：多窗紧凑版在 1.45× 下「名称 + 代码 + 市场 + 状态 + 时间 + ⋯」必裁；按字号分档隐藏次要信息（≥1.3 或 <240vp 隐藏状态/时间），1.0× 保留，避免一刀切丢信息。
