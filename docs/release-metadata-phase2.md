## 2. 详细描述（可直接粘贴）

小杨股票是一款面向学习与研究场景的**模拟**股票工具。

【核心能力】
- **自选与分组**：50 只上限、7 个自定义分组、系统组自动派生（创业板/科创板/融资融券），支持多选添加、部分成功提示与 5 秒撤销。
- **行情与详情**：11 列自选表 + 卡片视图（2/3/4/5 列自适应）；详情含报价、8 个周期图表、盘口、成交明细，支持横屏双栏。
- **搜索**：代码/名称/拼音首字母多级匹配、历史与热搜、空词浏览全部股票。
- **模拟交易**：本地假撮合的买卖、委托列表（7 状态）、撤单、成交回执；**不接入任何券商，不产生真实委托与资金变动**。
- **持仓与收益**：总市值/当日盈亏/累计盈亏/仓位/成本，口径在页面明示。
- **深色模式与字号**：跟随系统深浅色，支持 1.0~1.45× 字号，全站对比度达 4.5:1（深色）。

【重要说明】
本应用**不联网、不上传、不采集任何个人信息**，无账号体系；全部行情、成交、持仓、委托数据均由本机算法生成，
仅供学习参考，**不构成任何投资建议**。应用内常驻「模拟数据 · 仅供学习参考」提示。
首页与资讯页为占位页面（下阶段开放），不影响已提供功能的使用。

## 3. 分类与资质（待确认）

| 选项 | 说明 | 需要的资质 | 建议 |
|---|---|---|---|
| A. 金融理财 | 与「股票」语义最贴近，但审核对金融类最严 | 营业执照 + 金融相关许可/说明（**无牌照则大概率被拒**） | ⚠️ 风险高 |
| B. 教育 / 学习工具 | 与「模拟、学习参考、不构成投资建议」的定位一致 | 一般只需隐私政策 + 说明 | ✅ **推荐** |
| C. 工具 / 效率 | 兜底选项，语义偏弱 | 同上 | 可选 |

> 结论：按本项目「个人开发、无牌照、数据 100% 本机模拟」的口径，**建议 B（教育/学习工具）**，
> 并在详细描述里明确「模拟数据、不构成投资建议」。若你坚持 A，需先取得资质，否则会因资质缺失被拒（登记为外部阻塞）。

## 5. 测试账号说明（提审必填）

- 本应用**无需登录**，无真实账号体系；
- 模拟账户由首启自动创建：`500****45`（主）/ `500****65`（次），初始资金 500,000 / 60,000；
- 交易链路：自选 → 点股票 → 详情「去交易」→ 买入/卖出 → 确认 → 首次提交会弹「模拟交易风险揭示」→ 我已了解并继续；
- 委托/持仓：自选页标题「当日委托」→ 委托页标题「持仓」。
