# M11 持仓收益口径（AC-121）

> 版本：v1.0 · 2026-11-14 · 状态：**M11 已实现并验收**（公式纯函数 + 单测 + 3 组手工复核）
> 适用：持仓页（`features/account`）、详情「已持有」、交易弹窗「已持有」。
> 实现：`commons/data/src/main/ets/rules/PositionRules.ets`；单测：`commons/data/src/test/PositionRules.test.ets`、`LocalPositionProvider.test.ets`。

---

## 1. 定义

| 项 | 定义 | 说明 |
|---|---|---|
| 估值价 P | 行情最新价 > 0 时取最新价；否则取持仓记录上的「最近一次有效价」`lastPrice` | 停牌/退市行情快照的 `last`/`prevClose` 都是 `null`，只能回放最近有效价 |
| 成本价 | 加权买入成本（`trade_account_v1.holdings[].costPrice`） | 买入成交按「总成本 ÷ 总数量」重算，两位小数 |
| 成本额 | 成本价 × 持仓数量 | 含未估值行（便于对账） |
| 市值 | P × 持仓数量 | 无估值价（P = null）时为 `null`，页面 `--`，**不计入市值合计** |
| **累计盈亏** | 市值 − 成本额 | 无估值价时为 `null` |
| **累计盈亏率** | 累计盈亏 ÷ 成本额 × 100 | 成本额 ≤ 0（0 成本/负成本脏数据）时为 `null`（页面 `--`） |
| **当日盈亏** | (P − 昨收) × 持仓数量 | 昨收取当次行情快照；停牌/退市（昨收缺失）**计 0** |
| **仓位** | 个股市值 ÷ 持仓总市值 × 100 | 只计有估值的行；无估值行 `--`；同一账户内合计 100% |
| 可卖数量 | = 持仓数量（M10 简化） | **本期不做 T+1 冻结**，见 §5 |
| 汇总 | 总市值 / 当日盈亏 / 累计盈亏 / 成本额 / 只数 | 只累加有估值的行；未估值只数单独给「N 只未估值」 |

**成本口径 `costBasis = 'withoutFee'`**：本地撮合按**委托价**成交，不计佣金、印花税、过户费。
页面常显「累计盈亏按成本价计算，不含交易费用」（AC-121 要求明示）。

**四舍五入**：市值 / 盈亏 / 比率统一两位小数（`round2`），与行情、卡片、交易同口径。

## 2. 边界规则

| 场景 | 规则 | 单测 |
|---|---|---|
| 0 持仓（脏数据） | 市值/盈亏/盈亏率/当日盈亏全 `null` | `zero_qty_has_no_value` |
| 负成本（-10） | 市值与累计盈亏照算，**盈亏率为 `null`** | `negative_cost_ratio_is_null` |
| 0 成本 | 累计盈亏 = 市值，**盈亏率为 `null`** | `zero_cost_ratio_is_null` |
| 停牌/退市 | 用 `lastPrice` 估值；现价列 `--` + 「停」标签；**当日盈亏 0** | `suspended_uses_last_known_and_zero_day_pnl`、`suspended_falls_back_to_last_price` |
| 无任何有效价 | 现价 `--`、市值/盈亏 `null`、仓位 `null`，汇总标「N 只未估值」 | `missing_price_marks_unvalued` |
| 昨收缺失/非法（≤0） | 当日盈亏计 0（不虚构波动） | `invalid_prev_close_gives_zero_day_pnl` |
| 连续 10 个交易日停牌 | 仍按 `lastPrice` 估值，不自动清零 | 口径约定（无单独单测） |
| 排序 | 市值/盈亏/盈亏率，空值**恒末尾**，循环「降 → 升 → 取消」 | `sort_*`、`compare_nullable_*` |

## 3. 三组手工复核（AC-121「样例数据可手工复核」）

数据来自真机主账户种子（见 `TradeAccountStore.seed()` 与 `MarketSeeds` 基价），对应证据

| 组 | 标的 | 数量 | 成本价 | 现价 | 市值 | 累计盈亏 | 盈亏率 | 仓位 |
|---|---|---|---|---|---|---|---|---|
| A | 601318 中国平安 | 1,000 | 45.00 | 48.90 | 48,900.00 | **+3,900.00** | **+8.67%** | 55.67% |
| B | 000858 五粮液 | 200 | 150.00 | 142.80 | 28,560.00 | **−1,440.00** | **−4.80%** | 32.51% |
| C | 600036 招商银行 | 300 | 30.00 | 34.62 | 10,386.00 | **+1,386.00** | **+15.40%** | 11.82% |

手工复核：

```
A: 1000 × 48.90 = 48,900.00            48,900 − 45,000 = +3,900      3,900 / 45,000 = +8.67%
B:  200 × 142.80 = 28,560.00           28,560 − 30,000 = −1,440     −1,440 / 30,000 = −4.80%
C:  300 × 34.62 = 10,386.00            10,386 −  9,000 = +1,386      1,386 /  9,000 = +15.40%

汇总：市值 48,900 + 28,560 + 10,386 = 87,846.00
      成本 45,000 + 30,000 +  9,000 = 84,000.00
      累计 3,900 − 1,440 + 1,386    = +3,846.00     3,846 / 84,000 = +4.58%
      仓位 55.67 + 32.51 + 11.82 = 100.00%（两位小数舍入）
```

## 5. 已知限制（本期不做）

| # | 限制 | 影响 | 计划 |
|---|---|---|---|
| 1 | **无 T+1 冻结**：当日买入即可卖 | 与真实 A 股不一致；本地撮合按「持仓全可卖」 | 接本地后端时按成交日冻结 |
| 2 | **不处理除权除息**：成本价不因分红送转调整 | 长期持有后累计盈亏会失真 | 需要行情公司行动数据，模拟阶段不做 |
| 3 | **不含手续费**：佣金/印花税/过户费均不计 | 与真实收益有差；页面已明示 | 同上 |
| 4 | **停牌估值用最近有效价**，不是交易所官方收盘价 | 停牌期间市值可能偏离 | 有官方收盘价后替换 `lastPrice` 来源 |
| 5 | **主账户口径**：只展示账户列表第一个 | 第二账户的持仓不展示（多账户为 D58 预留） | 多账户时加账户切换 |
| 6 | 当日盈亏对「当日买入」不拆分 | 当日买入部分按昨收算，会含买入前的波动 | 需要逐笔成交基线 |
