## 4. 维护规则

1. **新增/改名/归档文档必须在本索引登记**，并写清状态（✅ 当前有效 / 🕐 时点快照 / 🗄 归档 / ⬜ 外部待补）。
2. **当前口径只写一处**：版本、HAP 体积、测试数只在「阶段二进度文档 §2」与「发版清单 §1~§4」维护；本索引顶部那行随发版同步，不另设明细。
3. **历史不改**：时点快照文档只加文首提示，不改正文数字；已关闭项与历史变更记录迁入 [阶段二进度-归档.md](阶段二进度-归档.md)。
4. **链接必须可达**：交付前自查 Markdown 相对链接（`validation/` 下的截图链接是 `../shots/…`，不是 `../../shots/…`）。
5. **合规文档是门禁输入**：`phase2-sdk-list.md`（X-01/X-02）、`privacy-policy.md` 抬头版本（X-05）、`gates.md`（规则说明）改动后必须跑 `node scripts/check-compliance.mjs`。
