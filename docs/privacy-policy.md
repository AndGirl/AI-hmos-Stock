## 适用范围

本政策适用于 HarmonyOS 应用「小杨股票」（`com.example.xiaoyangstock`，版本 1.2.0 及以后）。

## 一、我们如何处理你的数据

本应用**不联网、不上传、不同步**：没有账号体系，不采集设备标识、位置、通讯录、相册等任何个人信息。
你看到的行情、成交、持仓与委托**全部由本机算法模拟生成**（见 `commons/data/mock/` 与 `docs/api-contract-v1.md`）。

## 二、本机保存的信息

以下数据只保存在应用沙箱内（preferences 库 `xiaoyang_stock_v1`），卸载即删除：

| 键 | 内容 | 是否个人信息 |
|---|---|---|
| `watchlist_v1` | 自选集合与分组定义 | 否（用户自选行为，默认 45 只种子） |
| `search_history_v1` | 最近 10 条搜索词 | 否 |
| `view_pref_v1` | 列表/卡片视图偏好 | 否 |
| `quote_cache_v1` | 行情缓存（≤100 条） | 否 |
| `trade_account_v1` | 模拟账户、持仓、成本价 | 否（伪造账户号 `50012345`/`50098765`） |
| `trade_orders_v1` / `order_journal_v1` | 模拟委托与幂等流水 | 否 |
| `privacy_consent_v1` | 同意状态：`{agreed, version, agreedAt}` | 否（仅本机时间戳） |
| `trade_risk_v1` | 首笔风险揭示已读标记 | 否 |

## 三、权限说明

本应用**未申请任何系统权限**：不申请网络、位置、通讯录、相机、麦克风、存储等权限，
因此不存在基于权限的数据采集。连接状态（正常/弱网/断线）是**本地模拟**的，不读取真实网络。
完整清单见 [phase2-sdk-list.md](phase2-sdk-list.md) §3。

## 四、第三方组件

仅使用开源图表库 **`@ohos/mpchart` 3.0.31（Apache License 2.0）** 在设备本地绘制 K 线与分时图，
该组件不采集、不上传任何数据。应用内**无广告、无统计、无推送类 SDK**；埋点仅写本机 hilog
（`commons/basic/services/Analytics.ets`，登录态/持仓/金额一律不进参数）。清单见
[phase2-sdk-list.md](phase2-sdk-list.md) §2。

## 五、数据共享与披露

我们不共享、不转让、不公开披露你的任何信息；也没有可共享的第三方。全部数据仅存在于本机。

## 六、未成年人保护

本应用面向学习与研究场景，不提供真实证券投资服务，模拟交易不产生真实委托与资金变动；
未成年人请在监护人指导下使用。

## 七、你的权利

- **查看**：首页 →「隐私政策」（同意后常驻）；
- **撤回同意**：首页 →「撤回同意」，或隐私政策页底部「撤回同意」（二次确认后回到首启同意页，本机数据不删除）；
- **删除**：卸载应用即清除全部本机数据。

## 八、免责声明与联系方式

行情与交易均为**模拟数据**，仅供学习参考，**不构成任何投资建议或收益承诺**；应用内常驻
「模拟数据 · 仅供学习参考」（`GlobalBanner`）与「模拟交易 · 不产生真实委托」（委托页）。
如对本政策有疑问，请联系：**上架前填写联系邮箱**。
