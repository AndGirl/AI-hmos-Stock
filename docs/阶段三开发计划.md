> **与二期进度文档的差异（登记）**：[阶段二进度文档](阶段二进度文档.md) §E 写「客户端只换 `QuoteChannel`／`LocalPositionProvider` 的内层实现」。三阶段收敛为**只换行情内层**——持仓 `LocalPositionProvider` **不动**（D61）。原因：持仓估值本就由客户端按 `PositionRules` 纯函数从「本地持仓 + 行情快照」算出，把持仓搬到服务端会连带要求交易也过网（+8~10 人日，且无新增验收收益）。此差异在 T9 收口时回写二期进度文档。

### 4.3 三阶段补白（稿上没有 / 契约没写的边界，实现必须有）

| # | 场景 | 默认规则 |
|---|---|---|
| G3-1 | 后端未启动 | 客户端探活 3s 失败 → 回落 `sandbox`；**banner 一条**「本地后端未连接，已回落到本地模拟」（≤4s 自动消失）；不弹窗、不阻塞首屏 |
| G3-2 | 后端中途宕机 | 断连 → `ConnectionHub` 5s 内 offline → 缓存冻结 + 置灰 55% + 单条 banner；恢复后 1s 内 online 并**自动重订阅**（沿用二期退避，不自建第二套） |
| G3-3 | 订阅超限 | 服务端上限 **8 连接 / 每连接 200 code**；超出以 WS `error{reason:'internal'}` 下发并断开（**不扩 `QuoteErrorReason` 枚举**，登记为口径限制） |
| G3-4 | 端口被占 | 启动直接失败并打印占用 PID，**不自动换端口**（客户端只认 8080）；`status` 给出处置命令 |
| G3-5 | 前后端时钟偏差 | 后端 `snapshotTime` 用本机时钟；客户端只验**单调性**（既有 `stale_time`），跨机偏差不影响投递 |
| G3-6 | 演示标注 | 「模拟数据 · 仅供学习参考」**常显不变**；「本地后端」字样只出现在调试面板与隐私政策，**不新增用户可见入口** |

### 6.3 日常启停与观测

| 命令 | 作用 | 期望 |
|---|---|---|
| `scripts\backend.ps1 start` | 后台起服并等待就绪（≤3s） | `BACKEND READY pid=… port=…` |
| `scripts\backend.ps1 status` | 进程 + `/healthz` + rport 三态 | `pid=… health=ok conns=1 subs=45 session=demo-open` |
| `scripts\backend.ps1 logs -f` | 跟随日志 | 结构化行 + 慢请求（>500ms）单行告警 |
| `scripts\backend.ps1 stop` | 优雅停机（关连接 → 写退出日志 → 清 PID → `hdc rport remove`） | `BACKEND STOPPED`，无残留进程与端口 |
| `scripts\backend.ps1 restart` | `stop` + `start` | 同上 |
| `scripts\backend.ps1 start -WithRport` | 起服并自动做反代 | READY 后打印 `RPORT READY tcp:8080` |
| `scripts\backend.ps1 start -Debug` | 起服并开放 `/debug/*`（限流注入） | 日志出现 `debug endpoints enabled` |

### 6.4 真机连通（3 步 + 3 个常见失败）

| 步 | 动作 | 判据 |
|---|---|---|
| 1 | 确认设备在线 | `hdc list targets` 有且仅有一个目标（多设备用 `-t <sn>`） |
| 2 | 建反代 | `hdc rport tcp:8080 tcp:8080` 无报错；`hdc rport list` 能看到映射 |
| 3 | 真机访问 | `hdc shell "curl -s -m 3 http://127.0.0.1:8080/healthz"` 返回 `{"ok":true…}` |

常见失败与处置：

| 失败现象 | 根因 | 处置 |
|---|---|---|
| `hdc rport` 报端口占用 | 上次未清理 / 本机已有进程占 8080 | `hdc rport remove tcp:8080`，再查占用 PID（G3-4） |
| 真机访问超时 | 反代未生效 / 设备休眠断 USB | 重做第 2 步；`hdc shell` 先 `ping` 本机心跳，必要时重插线 |
| 模拟器不支持 `rport` | 模拟器网络栈差异 | 备用：`start -Host 0.0.0.0` + `AppConfig.localBaseUrl` 指向 PC 局域网 IP（仅调试，登记 D62 覆盖 +0.5 人日） |

### 6.5 故障处置（4 场景，M15-4 固化为演练脚本）

| # | 场景 | 客户端预期（自动，不手工干预） | 恢复步骤 |
|---|---|---|---|
| 1 | 后端**未启动**就开 App | 3s 内回落 `sandbox`，行情照常跳动，banner 一条「已回落到本地模拟」 | `start` 后由调试面板切回「本地后端」，或杀进程重启让探活重新决策（回退是**启动时一次性**决策，不在运行期自动横跳） |
| 2 | 端口被占 | 启动失败，打印占用 PID 与处置命令 | 杀占用进程或 `stop` 残留实例后重启 |
| 3 | 运行中 `kill -9` | 5s 内 offline + 冻结置灰 + 单条 banner；**不崩溃、不白屏** | `start` → 客户端 1s 内自动重连并重订阅 |
| 4 | 真机拔网线 / 关 Wi-Fi | 同上（offline）；恢复后自动回 online | 无需操作 |
