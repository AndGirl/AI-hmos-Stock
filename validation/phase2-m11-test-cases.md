## 7. 复现步骤（真机）

```powershell
# 1. 全新数据（重置账户与委托，或清应用数据）
hdc -t <sn> shell "bm clean -n com.example.xiaoyangstock -d"
devecocli run --module entry --device <sn>

# 2. 进入持仓：自选页标题「当日委托」→ 委托页标题栏「持仓」

# 3. 空态/失败态/重置：长按「持仓」大标题 → 持仓调试（debug）
#    模拟加载失败 / 恢复加载 / 重置账户与委托（回种子）/ 清空持仓（空态）

# 4. AC-120「＋」：自选页「编辑」→ 勾选一只持仓股 → 移出 → 回持仓页
```
