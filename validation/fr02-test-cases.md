# FR-02 自选列表 · 测试用例集

> 版本：v1.1（对应 FR-02 规格 V4）· 编制：2026-11-11 · 状态：待评审
> 说明：本文件只描述验收用例，不含实现代码；数据全部为 Mock（见 §3）。
>
> **v1.1 修订（采纳 C1–C7）**
> - C1：规模基线由 200 行改为 **50 行（账号上限）**，200 行降为技术压测，不作产品验收。
> - C2：分组改为「系统组（按板块自动继承）+ 用户组（可叠加）」，「全部」为并集视图。
> - C4：排序状态收归单一 `SortState`，列头与 FR-03 排序面板共用。
> - C6：字体放大时数字列按比例等比加宽，允许横滑，不缩字号、不截断。
> - C7：断线/弱网/延迟统一为单一连接状态机与单一提示条。
>
> 横切条款以 `requirements/fr-common-spec.md` 为准（本文件涉及 CC-1、CC-2、CC-4、CC-6、CC-7）。

## 1. 范围

- 覆盖：列渲染与布局、刷新与渲染粒度、状态与异常、排序/分组/行交互、指数条联动、多端与可访问性。
- 不覆盖：卡片视图（FR-03）、添加自选流程（FR-04）、详情页（FR-06 起）、分屏/多窗比价（P2）。

## 2. 验收项（AC）与用例映射

| AC | 验收描述 |
|---|---|
| AC-01 | 进页 300ms 内出现骨架屏，数据到达后替换无闪白 |
| AC-02 | 50 行（账号上限规模）连续滚动无白块，帧率 ≥55fps；200 行为技术压测，不作验收 |
| AC-03 | 行情推送时只有对应行更新，其余行不重绘 |
| AC-04 | 价格变动高亮一次，1s 内连续变动不重复闪烁 |
| AC-05 | 空自选展示空态与「添加自选」入口 |
| AC-06 | 停牌行显示 `--` 与「停牌」标，仍可点击 |
| AC-07 | 连接状态按统一状态机呈现（在线/弱网/断线/延迟），提示出现与消失符合预期 |
| AC-08 | 平盘显示中性灰 `0.00`，不出现红/绿 |
| AC-09 | 系统字体放大 1.3× 后行内文字不截断不重叠，数字列等比加宽 |
| AC-10 | 加载失败展示错误态且可重试成功 |
| AC-11 | 11 列全量渲染，横滑可看全，表头与名称列冻结 |
| AC-12 | 切分组 Tab 时指数条与列表同批更新、无残留 |
| AC-13 | 1.0× / 1.3× 下 ≥1180vp 无横滑，富余宽度落在名称列；**1.45× 允许横滑**（不截断、不隐藏列） |

## 5. 执行与通过准则

- 用例总数 **40**：P0 29 条、P1 11 条。
- 准入：规格 V3 冻结、Mock 数据就绪、四档宽度可切换。
- 通过：P0 全部通过且无阻塞缺陷；P1 允许 ≤2 条已知问题并登记。
- 回归触发：列宽/列集变更、刷新策略变更、分组配置结构变更（C2）、指数条数据源变更、排序状态结构变更（C4）、连接状态机变更（C7）。
