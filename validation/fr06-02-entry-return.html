进得去，也回得来

详情页有 6 个入口、3 种载体、5 个返回来源。06.1 决定「进去之后长什么样」，06.2 决定「谁 push、push 什么、pop 回哪、恢复什么」。下面按可验收的粒度拆开。

入口 E1 ~ E8 载体 page / pane / window 防抖 300ms 验收 AC-53.1 ~ 53.4

01

三种载体，三种「进出」

只有 page 有导航栈；pane 是选中态变更，window 是独立实例。三者的返回语义完全不同。

page 全屏页
自选首页 → push → 详情 · 60**39 栈深 2
← pop ← 自选首页（原位） 返回不重建、不重新请求
pane 右栏嵌入
列表 详情 · 60**19 栈深 1（无导航）
切换选中只替换右侧 code：无 push、无动画、无返回键
window 分屏 / 多窗
列表 ⟂ 窗口 1 · 60**19 窗口 2 · 30**89 各自独立
关闭即销毁（归 FR-08）；详情只回调 onClose，不参与窗口管理

03

路由参数契约

只有四个参数，来源页的状态一律不进路由。

参数

code
必填。规范化后的市场 + 代码，如 SZ000001；非法即 404
from
watchlist / card / search / deeplink / window，只用于回退与埋点
entry
tap / select，区分点击与右栏选中
rank
搜索结果位次，从 1 起，用于转化埋点
① code 必须先规范化 大小写、市场前缀、空格统一后再入路由；否则同一只股票会出现两条栈记录。
② from 非法即按 deeplink 缺省或未知取值不报错、不阻断进入，只影响返回回退与埋点口径。
③ 状态不进 URL 滚动位置、分组、排序、横滑偏移都不进路由；来源页保活即恢复，避免参数膨胀与不一致。
04

返回语义

5 个返回来源，5 种去向；同一个「返回」不能出现两种行为。

① 顶部返回箭头

与系统返回完全等价，走同一个 pop 实现，不允许一个走 A 一个走 B。

详情→ pop →来源页

② 系统返回 / 侧滑

手势与返回键同源；半折叠悬停态下同样可用，A 页返回键需避让状态栏。

手势→ pop 一层 →来源页

③ 深链根

没有来源页，返回落到自选首页；再返回才退出应用。首页须先就绪。

详情→ pop →自选首页→ 退出

④ pane

没有返回。切换选中或离开页面即结束，不产生路由变化，也没有 pop 动画。

选中 A→ 切换 →选中 B

⑤ window

关闭按钮销毁该实例；窗口数量、布局与关闭策略归 FR-08，详情只回调。

窗口→ 关闭 →销毁实例

⑥ 加载中返回

立即 pop 并取消在途请求；不允许等骨架加载完再返回，也不允许返回后回填数据。

骨架→ 返回 →取消请求
手势分区：侧滑返回 vs 图表拖动
返回
图表长按 / 拖动 / 缩放区（从 20vp 之后开始响应）
屏幕左边缘 20vp 归系统返回手势，图表横向拖动只在边缘之外响应；否则用户滑图会误退。

06

防抖：300ms 到底防什么

只认第一次点击；跨行连点同样只进一次。窗口结束后才允许再次进入。

300ms 去抖窗口 · 只接受第一次
✓点击 1进入详情
✕点击 2丢弃
✕点击 3丢弃
✓点击 4可再次进入
0100200300400
场景规则理由
同一行连点300ms 内只认第一次，第二次丢弃已有约定（FR-02 TC-030）
两行快速连点300ms 内仍只认第一次以最后一次为准会连 push 两页，返回要按两次
首个首帧内点击无效防止 push 未完成时重复触发
返回后再点不受 300ms 限制去抖窗口只覆盖单次导航
pane 快速切换150ms 合并 + 取消在途请求不是导航，但请求与图表会抖动
深链重复唤起同 code 复用栈顶外部连点两次不应产生两层详情
07

异常入口

四种必须单独设计落点的入口；其余四种沿用详情内状态。

code 不存在 / 退市

404 态：文案 + 「返回」+「去搜索」，不显示骨架。

可返回

深链缺 code

不进入详情，回首页并提示「链接无效」。

不产生栈记录

冷启动深链

首页为根 + 启动图覆盖，详情压栈；返回落到首页。

可返回

断网深链

详情无缓存 → 错误态 + 重试，与列表离线缓存策略区分。

可返回
其余情况表现
停牌正常进入，价格类 -- + 停牌标，仍可返回
新股正常进入，昨收 / 涨跌 --
首次请求失败详情错误态 + 重试，头部返回保留
push 与返回交叉pop 后到达的响应必须丢弃（seq 或存活标记）
08

验收与待拍板

AC-53 拆成四个子项，逐项可测。

AC-53.1

入口落点正确

6 个入口在对应断点落到 page / pane / window；pane 内切换不发生路由跳转。

P0
AC-53.2

返回四项一致

滚动、选中、分组、横滑与进入前一致；不触发重新请求、不闪白。

P0
AC-53.3

去抖与竞态

300ms 内连点只产生一层栈；加载中返回无残留请求与回填。

P0
AC-53.4

异常入口

404、缺参、冷启动、断网四种均有明确落点且可返回。

P1
R1

冷启动深链的根

建议首页为根 + push；否则返回直接退出应用。

R2

去抖粒度

建议全局 300ms、以首次为准，跨行也只进一次。

R3

返回是否恢复键盘

建议不恢复；自动弹键盘会遮住结果。

R4

404 是否给「去搜索」

建议给，比只留返回更有出路。

R5

关联股票再进详情

建议一期不支持；二期限栈深 3。

R6

pane 去抖 150ms

建议够用，需配取消在途与只渲染最后一次。
