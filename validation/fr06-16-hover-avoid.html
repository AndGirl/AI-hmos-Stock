悬停态：把折痕当作两页的边界

半折叠进入 DESKTOP_MODE 后，详情页按折痕切成上屏「走势页」与下屏「数据与操作页」。折痕区域整段留白，只作边界，不放文字与交互；所有原有区块一个不删，只换归属。

触发 折叠屏 · 全屏 · 半折叠 · 折痕横向 示例画布 720 × 760 H1 指标入 B ✓ H2 盘口 / 内容并排 ✓ H3 边界 1px ✓
01 触发条件 02 两页切分 03 边界与避让 04 压缩阶梯 05 红线与边界场景 06 验收
01

触发条件

四道门全过才进悬停态；任意一道不过，保持常规布局，不劣化。

折叠屏display.isFoldable() 为 true；直板机直接结束
→
全屏窗口分屏 / 悬浮 / 自由窗口不触发
→
半折叠 + 折痕横向FOLD_STATUS_HALF_FOLDED；书本型设备通常出现在横屏
→
DESKTOP_MODE系统姿态回调；应用只消费，不自行推断

推论：pane 与 window 两种壳天然不涉及悬停——它们所在的分屏 / 多窗环境不会被系统判为悬停。悬停只属于 page 壳的第 4 种形态。

为什么这样切

图表拿到 174。指标下沉后，上屏整条竖向预算都给走势；图表不再被压到 110 以下的「装饰高度」。
数据归数据。指标与五档同属盘口信息，相邻摆放，读一眼不用来回扫屏。
两页都完整。上屏是一张完整走势页，下屏是一张完整数据页，没有哪一页只剩半截。

A

上屏 · 走势页

导航 / 报价 / 资讯 / 周期 Tab / 图表。只读为主，不滚动，首屏完整。返回键在此，需避让状态栏。

B

折痕 · 边界

高度 = max(折痕高/2 + 16, 16)vp。整段留白，中央一根 1px 中性线作两页分界；带内无文字、无可点元素。

C

下屏 · 数据与操作

指标单行 → 左盘口 / 右内容 → 动作栏。固定坞不滚动；只有右侧内容区可滚，底部避让导航条。

03

边界与避让

四类避让缺一不可；三处高度都必须动态刷新，只查一次迟早穿帮。

折痕

内容封顶 creaseTop；避让带 max(折痕高/2+16,16)vp，中央 1px 线作边界。

失效：文字压在畸变区，观感像「压折痕」

状态栏

进页查 TYPE_SYSTEM，A 页顶部交互（返回、标题）叠加该高度。

失效：返回键被状态栏盖住

导航条

查 TYPE_NAVIGATION_INDICATOR，B 页动作栏底部叠加该高度。

失效：去交易按钮压住小白条

坐标对齐

根组件 expandSafeArea 铺满后，折痕 display 坐标才可与窗口坐标直换。

失效：两页分界整体偏移

取源优先级：getLiveCreaseRegion（API 20+）→ getCurrentFoldCreaseRegion（API 10+）→ 屏幕中线兜底（标注为估算）。 rect 单位是 px，转 vp 用 除以 densityPixels。加 expandSafeArea 会关掉系统自动避让，必须成对补手动避让。 刷新时机：进页初始查询 + avoidAreaChange 监听 + 旋转 / 进出悬停后经 setTimeout(0) 复核。

04

高度不够时的压缩阶梯

只允许压缩，不允许删除区块；任何一档都不使用截断、省略号或整块隐藏。

L1 图表高度收缩：向下限 160vp 靠拢，节点不重建，只改高度参数
L2 指标两行 → 一行 6 列：字号不变，仅重排列数
L3 资讯条折叠为单行：点击与关闭保留，标题省略用滚动而非截断
L4 右侧内容区高度归零：Tab 仍可切换，内容进入滚动区
L5 A 页整体可滚：返回键与报价常驻顶部，其余内容依次进入滚动
05

红线与边界场景

四条红线里任意一条破了，悬停态在真机上一定出问题。

✕图表节点进 if/else

悬停分支里重建 Canvas 会丢缓存、闪黑、重绘一次。只改高度参数，节点常驻。

✕回调里做同步查询

折痕与避让查询一律 setTimeout(0) 派发到回调外；回调只切 isInHover 一个状态位。

✕用横屏判断压制悬停

isHoverLayout() 直接返回 isInHover。书本型设备悬停就发生在横屏，加方向守卫会永不切换。

✕监听只加不减

姿态、避让、尺寸三个监听必须在页面销毁时全部 off，否则返回再进会重复响应。

场景处理
悬停 + 自选设置弹层锚定 A 页的半模态，不跨折痕；遮罩不铺到 B 页
悬停 + 键盘（讨论输入）键盘避让优先，B 页盘口 / 内容区压缩，动作栏上移
悬停 + 断线两页同时置灰 + 顶部唯一 banner，沿用 CC-7.6，不新增策略
悬停 + 1.45× 字号走压缩阶梯，不换行溢出、不缩字号
旋转与折叠同时到达状态各自更新，以终态组合渲染，不做中间态特判
悬停时的分屏 / 全屏入口隐藏，系统姿态优先；退出悬停后恢复
SDK 未声明 WindowPostureMode降级：getFoldStatus 判半折叠 + windowSizeChange 复核全屏，非全屏强制清除
06

验收

三条，均可在真机用 hidumper 模拟折叠形态复现。

AC-66

悬停几何

进入悬停后 A 页高度等于 creaseTop、避让带 ≥16vp 且带内无文字与可点元素、B 页吃掉剩余高度；折痕取源三级降级均可用。

AC-67

完整性合同

8 个区块在悬停态全部存在；仅在高度不足时按 L1–L5 压缩，不出现整块消失或文字截断。

AC-68

避让动态刷新

旋转 / 折展 / 进出悬停后，状态栏与导航条避让在 1 帧内更新；无内容钻到系统栏下方。
